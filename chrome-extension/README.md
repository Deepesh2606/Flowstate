# FLOWSTATE Chrome Extension (Manifest V3)

Focus timer, live toolbar countdown badge, daily deep work goal ring, and automatic distraction site blocker for FLOWSTATE.

## How to Install in Chrome / Brave / Arc / Edge

1. Unzip `flowstate-chrome-extension.zip` (or locate the `chrome-extension` folder).
2. Open `chrome://extensions` in your browser.
3. Toggle **Developer mode** on (top-right corner).
4. Click **Load unpacked** and select the extracted `flowstate-chrome-extension` folder.
5. Pin **FLOWSTATE** to your toolbar for one-click focus sprints and live countdown badges.
